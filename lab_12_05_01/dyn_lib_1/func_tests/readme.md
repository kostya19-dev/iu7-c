## аргументы командной строки
./app.exe FILE_IN FILE_OUT [f]
- FILE_IN - файл ввода 
- FILE_OUT - файл вывода
- [f] -если указан, происходит фильтрация

- 03 - Сортировка элементов, расположенных по убыванию
- 04 - Сортировка элементов, расположенных по возрастанию

- 06 - Сортировка случайного массива с повторениями
