# Тесты для задания №1 лабораторной работы №6 варианта №3

## Входные данные
Аргументы командной строки (название файла, цена Р), файл структур;

## Выходные данные
Информация о продуктах, цена которых меньше Р;

## Позитивные тесты:
- 00 - в файле одна запись, длина названия продукта = 25 
- 01 - в файле несколько записей, упорядоченных по убыванию цены за единицу товара 
- 02 - в файле несколько записей, упорядоченных по возрастанию цены за единицу товара 
- 03 - в файле 15 записей в произвольном порядке 
- 04 - в файле несколько записей с одинаковой ценой 
- 05 - в файле несколько записей, нет продуктов дешевле Р;
- 06 - в файле несколько записей, все продукты дешевле Р;
- 07 - в файле несколько записей, Р - вещественное число, цены продуктов равны целой части P 


## Негативные тесты:
- 00 - не существующий файл
- 01 - пустой файл
- 02 - нет доступа к файлу
- 03 - аргументов командной строки > 2
- 04 - аргументов командной строки < 2
- 05 - цена отрицательна
- 06 - нулевое значение цены
- 07 - длина имени продукта больше 25 символов
- 08 - в качестве длины продукта подается пустая строка
- 09 - цена продуктов в файле < 0
- 10 - цена продуктов в файле = 0
- 11 - цена продуктов в файле вещественная
- 12 - цена продуктов не является числом
- 13 - фактическое количество записей в файле больше заявленного
- 14 - заявленное количество записей в файле меньше 0
- 15 - заявленное количество записей в файле равна 0
- 16 - заявленное количество записей в файле не является числом
- 17 - заявленное количество записей в файле вещественное
- 18 - записей в файле больше 15
- 19 - длина цены продукта равна 0 
- 20 - фактическое количество записей в файле меньше заявленного
