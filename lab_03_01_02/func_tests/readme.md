# Тесты для лабораторной работы 03, задания 01

## Входные данные

Целое число h (h <= 10), Целое число w (w <= 10).
`h * w` целых чисел `a[0][0]`, ... , `a[h-1]a[w-1]`

## Выходные данные

w целых чисел

## Позитивные тесты:

- 01 - 4 строки, 4 столбца, в 1 и 3 столбце чередуются положительные и отрицательные элементы
- 02 - 3 строки, 4 столбца, в 4 столбце чередуются положительные и отрицательные элементы
- 03 - 2 строки, 2 столбца, положительные и отрицательные элементы чередуются в каждом столбце
- 04 - 5 строк, 5 столбцов, положительные и отрицательные элементы чередуются в каждом столбце
- 05 - 3 строки, 3 столбца, чередования элементов нет
- 06 - 4 строки, 4 столбца, чередования элементов нет в 3 столбце
- 07 - 1 строка, 1 столбец

## Негативные тесты:

- 01 - В качестве количества строк введен символ
- 02 - В качестве количества столбцов введен символ
- 03 - Количество строк <= 0
- 04 - Количество столбцов <= 0
- 05 - Количество строк > 10
- 06 - Количество столбцов > 10
- 07 - В качестве элемента матрицы введен символ
