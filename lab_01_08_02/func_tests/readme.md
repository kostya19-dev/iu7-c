# Тесты для лабораторной работы №01 Задача №8

## Входные данные
Беззнаковое целое число a длиной 4 байта и целое число n

## Выходные данные
Результат сдвига в двоичной системе счисления

## Позитивные тесты:
- 01 - Нулевые значения
- 02 - Значения, сильно меньше двойки в 32 степени
- 03 - Проверка значения, результат сдвига которого близок к двойке в 32 степени
- 04 - Проверка значения, когда циклический сдвиг сдвигает также значимые нули и единицы
- 05 - Проверка циклического сдвига с большими значениями

## Негативные тесты:
- 01 - В качестве значения a введен символ
- 02 - В качестве значения n введен символ
- 03 - В качестве значения n введена строка
- 04 - Отрицательное значение n
- 05 - Отрицательное значение n
