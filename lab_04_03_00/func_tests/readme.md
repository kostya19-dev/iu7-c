# Тесты для лабораторной работы №04

## Входные данные
Строка in_string

## Выходные данные
Строка, которая содержит слова из первой сроки, отличающиеся от последнего слова, записанные в обратном порядке с удаленными повторными вхождениями первого символа

## Позитивные тесты:
- 01 - Все слова разные
- 02 - Несколько слов совпадают с последним
- 03 - Есть слово из одинаковых букв
- 04 - Все слова из одинаковых букв
- 05 - Слова состоят из букв и цифр
- 06 - Слова разделены множеством пробелов
- 07 - Множество разделителей перед первым словом и после последнего слова

## Негативные тесты:
- 01 - Исходная строка пустая
- 02 - В исходной строке только одно слово
- 03 - В исходной строке есть слово > 16 символов
- 04 - В исходной строке все слова > 16 символов
- 05 - Длина исходной строки > 256
- 06 - Все слова в исходной строке одинаковые
- 07 - Входная строка состоит только из разделителей
