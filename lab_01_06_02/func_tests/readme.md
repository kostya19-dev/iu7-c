# Тесты для лабораторной работы №01 Задача №6

## Входные данные
Значения координат вершин треугольника abc Xa, Ya, Xb, Yb, Xc, Yc и координаты точки Xp, Yp

## Выходные данные
Целое значение: 0 - если точка лежит внутри треугольника, 1 - если точка лежит на границе треугольника, 2 - если точка лежит вне треугольника

## Позитивные тесты:
- 01 - Целые неотрицательные координаты, точка внутри треугольника
- 02 - Целые неотрицательные координаты, точка вне треугольника
- 03 - Вещественные неотрицательные координаты, точка на границе треугольника
- 04 - Целые координаты, точка на границе треугольника
- 05 - Целые неотрицательные координаты, точка вне треугольника

## Негативные тесты:
- 01 - Одним из значений координат является символ
- 02 - Одним из значений координат является символ
- 03 - Одним из значений координат является символ
- 04 - Одним из значений координат является символ
- 05 - Некорректные значения вершин треугольника
- 06 - Треугольник вырождается в отрезок
