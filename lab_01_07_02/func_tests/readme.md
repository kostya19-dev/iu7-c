# Тесты для лабораторной работы №01 Задача №7

## Входные данные
Вещественные X и eps

## Выходные данные
Вещественные значения s(x), f(x), абсолютную и относительную погрешности

## Позитивные тесты:
- 01 - Проверка при x, далёком от границы области определения
- 02 - Проверка при сниженной точности eps
- 03 - Проверка при повышенной точности eps и малым x
- 04 - Проверка при большем x и малом eps
- 05 - Проверка при x равном 1

## Негативные тесты:
- 01 - Некорретное значение аргумента X
- 02 - В качестве значения X введен символ
- 03 - В качестве значения eps введен символ
- 04 - Отрицательное значение eps
- 05 - Отрицательное значение eps
- 06 - Значение eps больше 1
