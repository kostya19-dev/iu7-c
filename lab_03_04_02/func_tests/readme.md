# Тесты для лабораторной работы 03, задания 04

## Входные данные

Целое число h (h <= 10), Целое число w (w <= 10).
`h * w` целых чисел `a[0][0]`, ... , `a[h-1]a[w-1]`

## Выходные данные

Максимальное число, которое оканчивается на 5 и находится под побочной диагональю матрицы

## Позитивные тесты:

- 01 - 4 строки, 4 столбца, один подходящий под условие элемент
- 02 - 3 строки, 3 столбца, несколько подходящих под условие элементов
- 03 - 2 строки, 2 столбца, один подходящий под условие элемент
- 04 - 3 строки, 3 столбца, матрица состоит из одинаковых элементов, подходящих под условие
- 05 - 5 строк, 5 столбцов, один подходящий под условие элемент
- 06 - 5 строк, 5 столбцов, несколько подходящих под условие элементов
- 07 - 7 строк, 7 столбцов, матрица состоит из одинаковых элементов, подходящих под условие

## Негативные тесты:

- 01 - В качестве количества строк введен символ
- 02 - В качестве количества столбцов введен символ
- 03 - Количество строк <= 0
- 04 - Количество столбцов <= 0
- 05 - Количество строк > 10
- 06 - Количество столбцов > 10
- 07 - В качестве элемента матрицы введен символ
- 08 - Матрица размером 1 на 1
- 09 - Подходящий элемент отсутствует
- 10 - Матрица не квадратная
