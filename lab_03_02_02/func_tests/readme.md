# Тесты для лабораторной работы 03, задания 02

## Входные данные

Целое число h (h <= 10), Целое число w (w <= 10).
`h * w` целых чисел `a[0][0]`, ... , `a[h-1]a[w-1]`

## Выходные данные

Целочисленная матрица

## Позитивные тесты:

- 01 - 2 строки, 3 столбца, во 2 строке есть подходящие элементы
- 02 - 4 строки, 4 столбца, в 1 и 4 строке есть подходящие элементы
- 03 - 3 строки, 3 столбца, во всех строках есть подходящие элементы
- 04 - 4 строки, 3 столбца, во всех строках есть подходящие элементы
- 05 - 2 строки, 2 столбца, ни в одной строке нет подходящих элементов
- 06 - 4 строки, 3 столбца, ни в одной строке нет подходящих элементов
- 07 - 4 строки, 3 столбца, подходящие элементы есть во всех строках, кроме 3

## Негативные тесты:

- 01 - В качестве количества строк введен символ
- 02 - В качестве количества столбцов введен символ
- 03 - Количество строк <= 0
- 04 - Количество столбцов <= 0
- 05 - Количество строк > 10
- 06 - Количество столбцов > 10
- 07 - В качестве элемента матрицы введен символ
- 08 - Матрица состоит из 1 элемента
