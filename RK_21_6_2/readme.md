## Позитивные тесты

1. Ввод корректного положительного целого числа для размера массива:
   - Ввод: 5
   - результат: Программа выдаст запрос на ввод элементов массива

2. Ввод корректных целых чисел для элементов массива:
   - Ввод: 1 2 3 4 5
   - результат: 2 4 6 8 4

3. Изменение элементов массива при размере равном 1:
    - Ввод: 2
    - результат: 0

## Негативные тесты

1. Ввод некорректного символа для элемента массива:
   - Ввод: 1 2 3 xyz 5
   - результат: Ошибка: некорректный ввод элемента массива.

2. Ввод некорректного символа для размера массива:
   - Ввод: abc
   - результат: Ошибка: некорректный ввод размера массива.
   
3. Ввод отрицательного числа для размера массива:
   - Ввод: -3
   - результат: Ошибка: некорректный ввод размера массива.

4. Ввод нуля для размера массива:
   - Ввод: 0
   - результат: Ошибка: некорректный ввод размера массива.
   
5. Ввод вещественного числа для размера массива:
   - Ввод: 3.5
   - Ожидаемый результат: Ошибка: некорректный ввод размера массива.
