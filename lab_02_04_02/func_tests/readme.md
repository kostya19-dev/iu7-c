# Тесты для лабораторной работы 02, задания 04

## Входные данные

N (N <= 10) целых чисел a[0], ... , a[N-1]. Признак окончания ввода (что-либо, не
воспринимаемое как число)

## Выходные данные

Не более N целых чисел

## Позитивные тесты:

- 01 - обычный тест
- 02 - один элемент в массиве
- 03 - одиа@наковые элементы в массиве
- 04 - массив отсортирован изначально
- 05 - наличие отрицательных чисел
- 06 - 10 элементов в массиве
- 07 - количество элементов больше 10

## Негативные тесты:

- 01 - ввод перым элементом буквы, т.е. количество элементов в массиве равно
нулю
- 02 - отсутствие значений
