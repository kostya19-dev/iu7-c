# Тесты для лабораторной работы 03, задания 03

## Входные данные

Целое число h (h <= 10), Целое число w (w <= 10).
`h * w` целых чисел `a[0][0]`, ... , `a[h-1]a[w-1]`

## Выходные данные

Целочисленная матрица

## Позитивные тесты:

- 01 - 2 строки, 2 столбца, матрица не отсортирована
- 02 - 3 строки, 4 столбца, матрица не отсортирована
- 03 - 3 строки, 3 столбца, матрица отсортирована
- 04 - 4 строки, 5 столбцов, матрица отсортирована
- 05 - 3 строки, 3 столбца, матрица состоит только из 0
- 06 - 4 строки, 4 столбца, матрица состоит из одинаковых элементов
- 07 - 2 строки, 4 столбца, матрица отсортирована в обратном порядке

## Негативные тесты:

- 01 - В качестве количества строк введен символ
- 02 - В качестве количества столбцов введен символ
- 03 - Количество строк <= 0
- 04 - Количество столбцов <= 0
- 05 - Количество строк > 10
- 06 - Количество столбцов > 10
- 07 - В качестве элемента матрицы введен символ
