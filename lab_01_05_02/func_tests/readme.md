# Тесты для лабораторной работы №01 Задача №5

## Входные данные
Вводится целое неотрицательное значения n

## Выходные данные
Выводится целый результат вычисления числа Фибоначчи 

## Позитивные тесты:
- 01 - Нулевое значение аргумента функции Фибоначчи
- 02 - Значение аргумента функции Фибоначчи равно 1
- 03 - Значение аргумента функции Фибоначчи равно 2
- 04 - Значение аргумента функции Фибоначчи равно 10
- 05 - Значение аргумента функции Фибоначчи равно 30

## Негативные тесты:
- 01 - Введен символ
- 02 - Введена строка
- 03 - Отрицательное значение аргумента функции Фибоначчи
- 04 - Значение аргумента функции Фибоначчи, при котором происходит переполнение
- 05 - Значение аргумента функции Фибоначчи, при котором происходит переполнение
