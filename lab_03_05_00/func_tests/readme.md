# Тесты для лабораторной работы 03, задания 05

## Входные данные

Целое число h (h <= 10), Целое число w (w <= 10).
`h * w` целых чисел `a[0][0]`, ... , `a[h-1]a[w-1]`

## Выходные данные

Целочисленная матрица, измененная согласно варианту

## Позитивные тесты:

- 01 - 4 строки, 4 столбца, несколько простых чисел
- 02 - 2 строки, 3 столбца, несколько простых чисел
- 03 - 2 строки, 2 столбца, одно простое число
- 04 - 5 строк, 2 столбца, одно простое число
- 05 - 3 строки, 3 столбца, все элементы матрицы простые
- 06 - 4 строки, 4 столбца, ровно два простых элемента
- 07 - 2 строки, 2 столбца, все элементы матрицы простые, кроме одного
- 08 - 2 строки, 2 столбца, проверка, что отрицательные числа, которые по модулю простые, не являются простыми

## Негативные тесты:

- 01 - В качестве количества строк введен символ
- 02 - В качестве количества столбцов введен символ
- 03 - Количество строк <= 0
- 04 - Количество столбцов <= 0
- 05 - Количество строк > 10
- 06 - Количество столбцов > 10
- 07 - В качестве элемента матрицы введен символ
- 08 - В матрице отсутствуют простые числа
- 09 - 2 строки, 2 столбца. Отсутствую простые числа, но присутствуют
отрицательные и простые по модулю числа
