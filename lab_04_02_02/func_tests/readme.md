# Тесты для лабораторной работы №04

## Входные данные
Строка string1
Строка string2

## Выходные данные
Пары "слово yes|no"

## Позитивные тесты:
- 01 - Одно слово из первой строки есть во второй строке
- 02 - Все слова из первой строки есть во второй строке
- 03 - Ни одного слова из первой строки нет во второй строке
- 04 - Все слова первой строки одинаковые и есть во второй строке
- 05 - Все слова первой строки одинаковые и отсутствуют во второй строке
- 06 - Все слова в первой строке разделены множеством разных разделителей
- 07 - Все слова в первой строке разделены множеством пробелов

## Негативные тесты:
- 01 - Первая строка пустая
- 02 - Вторая строка пустая
- 03 - Первая строка длиннее 256 символов
- 04 - Вторая строка длиннее 256 символов
- 05 - В первой строке слово длиннее 16 символов
- 06 - Во второй строке слово длиннее 16 символов
