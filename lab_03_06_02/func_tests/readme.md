# Тесты для лабораторной работы 03, задания 06

## Входные данные

Целое число h (h <= 10), Целое число w (w <= 10).
`h * w` целых чисел `a[0][0]`, ... , `a[h-1]a[w-1]`

## Выходные данные

Целочисленная матрица, заполненная ходом быка

## Позитивные тесты:

- 01 - 1 строка, 1 столбец
- 02 - 2 строки, 2 столбца
- 03 - 4 строки, 4 столбца
- 04 - 1 строка, 2 столбца
- 05 - 4 строки, 2 столбца
- 06 - 5 строк, 1 столбец
- 07 - 2 строки, 5 столбцов

## Негативные тесты:

- 01 - В качестве количества строк введен символ
- 02 - В качестве количества столбцов введен символ
- 03 - Количество строк <= 0
- 04 - Количество столбцов <= 0
- 05 - Количество строк > 10
- 06 - Количество столбцов > 10
