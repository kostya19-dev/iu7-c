# Тесты для лабораторной работы №11
## Входные данные
- Строки, содержащие форматируемые данные.
- Размер буфера, в который будет записана строка.

## Выходные данные
- Количество символов, которые были бы записаны в буфер (включая завершающий нулевой символ, если он помещается в буфер).
- Строка, записанная в буфер.

## Позитивные тесты:
- **01** - Обычное форматирование строки с подстановкой текста:
  - Входные данные: `"Hello, %s!"`, `"World"`
  - Ожидаемый результат: длина 13, строка `"Hello, World!"`
- **02** - Форматирование одного символа:
  - Входные данные: `"Character: %c"`, `'A'`
  - Ожидаемый результат: длина 12, строка `"Character: A"`
- **03** - Обработка нулевой строки:
  - Входные данные: `"String: %s"`, `NULL`
  - Ожидаемый результат: длина 14, строка `"String: (null)"`
- **04** - Обработка переполнения буфера:
  - Входные данные: `"Hello, %s!"`, `"World"`
  - Ожидаемый результат: длина 9, строка `"Hello, Wo"`
- **05** - Форматирование строки без параметров:
  - Входные данные: `"Hello World!"`
  - Ожидаемый результат: длина 12, строка `"Hello World!"`
- **06** - Пустая строка:
  - Входные данные: `"%s"`, `""`
  - Ожидаемый результат: длина 0, пустая строка.
- **07** - Несколько спецификаторов:
  - Входные данные: `"Char: %c, String: %s"`, `'X'`, `"Hello"`
  - Ожидаемый результат: длина 22, строка `"Char: X, String: Hello"`
- **08** - Очень большой ввод:
  - Входные данные: `"A very long string with multiple words: %s, %c"`, `"Testing"`, `'B'`
  - Ожидаемый результат: длина 50, строка `"A very long string with multiple words: Testing, B"`
- **09** - Разные типы в одном формате:
  - Входные данные: `"Char: %c, String: %s, %c"`, `'X'`, `"Test"`, `'Y'`
  - Ожидаемый результат: длина 24, строка `"Char: X, String: Test, Y"`

## Негативные тесты:
- **01** - Буфер слишком мал для записи данных:
  - Входные данные: `"A"`, буфер размером 1
  - Ожидаемый результат: длина 0, буфер пуст (не помещается даже завершающий `\0`).
- **02** - Пустой формат без данных:
  - Входные данные: пустая строка с буфером размером 1.
  - Ожидаемый результат: длина 0, буфер пуст.
- **03** - Форматирование строки с невалидным указателем (NULL):
  - Входные данные: `%s`, `NULL`, буфер достаточного размера.
  - Ожидаемый результат: длина 7, строка `"(null)"`.

## Описание тестов:
Модульные тесты для функции `my_snprintf` включают проверку:
- Правильности обработки строковых данных (с использованием `%s`).
- Форматирования одиночных символов (с использованием `%c`).
- Корректности работы с переполнением буфера.
- Правильности обработки нулевых строк и `NULL`.
- Множества спецификаторов в одном формате.
- Разных типов данных (символов и строк).
