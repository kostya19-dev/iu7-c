# Тесты для программы полиномов
## Входные данные
Пользователь вводит команду (`val`, `ddx`, `sum`, `dvd`) и соответствующие аргументы.

## Выходные данные
Программа возвращает результат вычислений или сообщение об ошибке.

## Позитивные тесты:
- 01 - Команда `val`: вычисление значения полинома для заданного `a`.
- 02 - Команда `ddx`: вычисление производной полинома.
- 03 - Команда `sum`: сложение двух полиномов.
- 04 - Команда `dvd`: разделение полинома на четные и нечетные степени.

## Негативные тесты:
- 01 - Неизвестная команда.
- 02 - Некорректный ввод, например, буквы вместо чисел.
