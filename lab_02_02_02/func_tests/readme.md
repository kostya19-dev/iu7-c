# Тесты для лабораторной работы 02, задания 02

## Входные данные

Целое число N (N <= 10). N целых чисел a[0], ... , a[N-1]

## Выходные данные

Не более N целых чисел

## Позитивные тесты:

- 01 - обычный тест
- 02 - обычный тест
- 03 - проверка на ввод чисел с незначащими нулями
- 04 - ввод чисел из одной цифры

## Негативные тесты:

- 01 - буква вместо количества элементов в массиве
- 02 - буква вместо элемента массива
- 03 - количество элементов в массиве равно нулю
- 04 - количество элементов в массиве больше 10
- 05 - отсутствие данных
- 06 - отсутствие в введённых данных нужных чисел
- 07 - количество элементов больше 10
- 08 - отрицательное количество элементов
